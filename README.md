# Blog de Rocío

Contenido publicado de https://blogderociobelen.wordpress.com/ exportado el 26 de octubre de 2026.

## Archivos

- `contenido/publicaciones.json`: entradas y páginas publicadas, con sus fechas, direcciones y contenido HTML.
- El respaldo XML completo permanece únicamente en el computador y está excluido de Git.

Las imágenes todavía utilizan las direcciones del blog original. Este repositorio guarda el contenido para preparar una futura versión del sitio; todavía no es un sitio publicado con GitHub Pages.

Los textos y las imágenes conservan los derechos de sus respectivos titulares.
